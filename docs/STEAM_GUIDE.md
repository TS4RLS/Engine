# Steam Artwork Guide

This project ships a full set of custom Steam library artwork, in
`assets/steam/`, sized to Steam's current library grid requirements, for
adding TS4RLS to your Steam library as a non-Steam game.

## Asset list

| File | Size | Steam slot |
|---|---|---|
| `cover.png` | 600×900 | Portrait grid capsule |
| `wide_cover.png` | 920×430 | Landscape grid capsule |
| `background.png` | 3840×1240 | Library hero |
| `logo.png` | 1280×720 | Library logo (transparent background) |

Don't have the source repo? Grab the same set as a single zip:

- **[⬇ Download TS4RLS_Steam_Assets.zip](https://github.com/TS4RLS/Engine/raw/steam_assets/TS4RLS_Steam_Assets.zip)**
  — a permanent link, always up to date with the latest release.
- The app's **About** tab has a **Save Steam artwork (.zip)...** button
  that saves this same set anywhere you like.
- Or download it as an asset on any [Release](https://github.com/TS4RLS/Engine/releases).

## Applying the artwork

1. Add the `TS4RLS`/`.exe` executable to Steam as a non-Steam game:
   **Steam → Games → Add a Non-Steam Game to My Library**.
2. In your Library, right-click the new entry → **Manage** →
   **Set custom artwork**, and upload the matching file from
   `assets/steam/` (or the zip above) for each slot (grid, hero, logo).

For the full walkthrough with screenshots, see this community guide:
[Adding custom artwork to non-Steam games](https://steamcommunity.com/sharedfiles/filedetails/?id=3582792038).
